# AngelaNexus 文档

AngelaNexus 采用**英文优先、四语言 APP 界面**体系。

## APP 界面语言

- **English — 英文（主语言 / 默认）**
- **简体中文 — 中文**
- **Русский — 俄语**
- **فارسی — 波斯语**

波斯语界面必须支持 RTL（从右到左）布局。

## 文档语言

英文是架构、API、实现契约、发布记录和开发者规范的规范性主文档。简体中文提供中文镜像；APP UI 的四种语言属于同等产品语言能力。

## 双语文档规范

1. 英文是规范性主文档。
2. 中文镜像不得改变英文主文档的架构或产品语义。
3. APP 的俄语和波斯语 UI 同样不能改变平台行为语义。
4. 技术标识符、协议名称、API 名称、版本号和代码符号保持不变。
5. 缺失翻译时统一回退到英文。
