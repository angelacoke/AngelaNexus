# AngelaNexus APP UI 设计基线

## 产品范围

本 UI 规范适用于 Android、iOS、Windows、macOS 和 Linux。Android 是第一个可执行 UI 表面；信息架构、语义状态和用户概念在平台之间共享。

## 设计方向

采用现代、模块化、自适应界面：

- 紧凑卡片
- 清晰的主要操作
- 浅色/深色主题
- 首页、配置、代理、规则、设置明确分区
- UI 只呈现 AngelaNexus Core/Platform Runtime 的真实状态

## 共享 UI 边界

共享 UI 负责：

- 导航
- 运行状态
- 配置/导入
- 节点、代理和策略组
- 路由与安全可视化
- GFW 观察
- 日志与诊断
- 账户与数据
- 备份/恢复
- 用户偏好

平台 Shell 负责：

- VPN/TUN
- 系统代理
- 权限
- 后台生命周期
- 通知
- 安全存储
- 网络接口
- 系统托盘/菜单栏
- 原生文件选择
- OS-specific firewall/routing

共享 UI 不得直接导入平台 API。

## 主导航

1. **首页** — 连接状态、流量、网络环境、快捷操作和运行状态。
2. **配置** — 订阅、本地文件、单节点、多节点导入。
3. **代理** — 节点、选择器、链式路径和内核无关的代理视图。
4. **规则** — 路由、防泄露、中国网络优化和 GFW 相关策略。
5. **设置** — 账户/数据、备份恢复、平台设置、安全、运行时诊断和外观。

## 账户与数据

设置中应提供账户身份、同步状态、备份历史、创建备份、恢复、选择性恢复、冲突处理、同步范围和设备列表。

必须明确区分：

- **共享账户数据** — 可以跨平台迁移；
- **平台状态** — 由各平台独立解释；
- **设备专属秘密** — 不进入普通同步或备份。

同步成功绝不能显示为代理启动成功或 VPN/TUN 已建立。

## 自适应布局

### 手机

五个主要模块使用底部导航。

### 平板

使用自适应导航栏或双栏布局。

### Windows / macOS / Linux

使用侧边栏、中央工作区和可选详情面板，并支持快捷键、上下文菜单、可调整窗口和托盘/菜单栏。

桌面不是简单放大的手机布局。

## UI 原则

- **模块化：** 可复用语义模块，策略逻辑不复制到 UI。
- **状态驱动：** UI 反映 Core、账户和平台真实状态。
- **渐进式展示：** 普通用户先看到简单操作，高级路由、安全、同步和诊断仍然可进入。
- **安全可见：** 防泄露、路由模式、VPN、DNS 和 GFW 相关决策可观察。
- **数据边界可见：** 用户可以看到哪些数据共享、哪些属于平台本地、哪些只能留在设备。
- **低资源：** 避免持续动画和无意义轮询，状态通过共享状态流更新。
- **自适应：** 不同屏幕保持相同语义。
- **无障碍：** 足够大的触控目标、动态字体、键盘导航、语义标签和足够对比度。
- **主题适配：** 跟随系统浅色/深色和平台外观能力。
- **必要时原生：** 共享语义不强迫所有平台使用完全相同的系统控件。

## 首页

首页保持紧凑，包含：

- 项目身份和 Core 状态；
- 主连接卡片；
- 上传/下载/会话指标；
- 网络与安全摘要；
- 同步状态；
- 快捷操作；
- 运行诊断。

只有 Core 报告实际 active execution state 后，连接卡片才能显示代理流量已经运行。

## 配置体验

支持：

- 订阅 URL；
- 本地配置文件；
- 单节点；
- 多节点及混合格式。

输入交给 Core 的 sniffing/import pipeline；在 Core 可以检测时，用户不需要手动选择执行后端。

## 备份/恢复体验

备份和恢复必须是明确的用户操作。破坏性变更前显示预览；数据模型允许时提供选择性恢复。

恢复顺序：

1. 验证账户和备份身份；
2. 验证 schema/version；
3. 预览变更；
4. 恢复共享账户数据；
5. 仅应用目标平台支持的状态；
6. 重新执行 Core 校验和安全检查；
7. 对不支持字段明确报告，不得声称已经应用。

## 代理体验

代理视图保持内核无关。公共节点字段始终可见，内核特有能力作为可选详情。链式组合使用图/列表表达 outbound stages，而不是固定角色名称。

## 规则体验

按意图分组：

- 网络路由；
- 隐私/防泄露；
- 中国网络优化；
- AI/服务路由；
- GFW 观察与响应；
- 用户覆盖规则。

UI 展示有效决策及证据来源，不静默改写用户策略。

## 实现状态

本文件是 UI 设计基线，不代表生产运行时已经全部实现。生产云认证、云存储、代理执行以及各平台原生运行时集成必须分别完成实现和验证。
